Artifact 01 — Conversational AI

RecycleBot SF

An AI-powered chatbot trained on SFPUC recycling guidelines. Helps SF residents instantly know where any item goes — compost, recycling, or landfill — through natural conversation.

Conversational AIChatbaseRAGPublic Service
Try RecycleBot SF →
Introduction
RecycleBot SF is a conversational AI assistant that helps San Francisco residents identify the correct disposal bin for any household item — built on official Recology guidelines using RAG architecture and deployed as a public embeddable widget.
Objective
Apply conversational AI and RAG to solve a real civic problem: eliminating recycling confusion for SF residents through a fast, accurate, bilingual chatbot.
Process
Designed using the 5-stage Design Thinking methodology. System prompt engineered using the Context + Task + Constraints framework. Tested with 8 items in EN/ES — 100% accuracy. 4-category response structure: Green, Blue, Black, and Special Disposal.
Tools & Tech
Chatbase · RAG · Recology SF official guidelines · Prompt engineering (Context + Task + Constraints) · Bilingual NLP
Unique Value
A four-category system — including Special Disposal for hazardous items — that goes beyond the standard 3-bin structure, providing accurate guidance where generic bots fail.
Relevance
Demonstrates RAG, prompt engineering, and iterative design — core AIML-500 competencies — through a deployed, bilingual, publicly accessible civic tool.

Clean, Clear & Safe

AI-powered product analyzer that identifies toxic compounds in consumer products and recommends 6 cleaner alternatives with real-time Amazon pricing and availability.

Claude APIAmazon Data APIVercelReal-time Data
Try Personal Shopper →
Introduction
Clean, Clear & Safe Personal Shopper is an AI tool that analyzes consumer products, identifies compounds of concern using scientific criteria (EWG, FDA, PubChem), assigns a CCS score from 0–100, and recommends 6 cleaner alternatives with real prices and images pulled live from Amazon.
Objective
Demonstrate that AI can connect to the real world in real time — going beyond static Q&A to return actionable results by integrating live external APIs with LLM reasoning.
Process
Iterated through 9+ versions. Compound scoring built on EWG, FDA, and PubChem criteria. Claude API generates structured JSON output. Amazon Data API retrieves live pricing and images. Deployed serverlessly on Vercel. Each iteration responded to specific interface and UX feedback.
Tools & Tech
Claude API · Amazon Data API · Vercel Serverless Functions · Node.js · JSON structured output · EWG / FDA / PubChem scientific criteria
Unique Value
Unlike static product databases, CCS combines real-time Amazon pricing with AI-driven toxicity scoring — turning ingredient analysis into actionable purchasing decisions.

Artifact 04 — Computer Vision & ML Pipeline

SnapSift AI

Intelligent Photo Organizer

AI-powered desktop app that filters, deduplicates, and organizes photos from any ZIP file using computer vision — 100% local, Privacy by Design.

Claude Vision APIComputer VisionPythonPrivacy by Design
⬇ Download for Mac ⬇ Download for Windows
Introduction
SnapSift AI is a locally-executed, privacy-first photo organization tool that uses AI to automatically filter, deduplicate, and organize photos from any ZIP file — combining computer vision, perceptual hashing, and natural language generation into a single end-to-end ML pipeline, without uploading any personal data to external servers.
Objective
Solve a real-world scale problem: WhatsApp datasets of 5,100+ mixed-content images where only a fraction qualifies as genuine personal photography — making manual classification impractical and demonstrating a full ML pipeline from ingestion to summarization.
Process
3 documented prompt engineering iterations refined classification accuracy. Model substitution from claude-opus to claude-haiku reduced cost by 95% (from ~$39 to under $2.50 for 5,100 images) while maintaining quality. Checkpoint system implemented for resilience. Validated on a 49-photo controlled set: 43% kept, 55% discarded, 2% flagged for review.
Tools & Tech
Python · Claude Vision API · Perceptual hashing · Natural language generation · Desktop packaging (Mac & Windows) · Privacy by Design architecture
Unique Value
The only AI photo organizer that runs 100% locally — no cloud upload, no data retention. Cultural classification bias was identified, documented, and mitigated through iterative prompt engineering, reflecting responsible AI development.
Relevance
Demonstrates computer vision, supervised classification, similarity detection, LLM summarization, and model iteration — the most complete ML pipeline in this portfolio — delivered as a production desktop application.
